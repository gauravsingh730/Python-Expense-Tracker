#  Python Expense Tracker

## Project Description
This is a beginner-friendly Python project that helps users track their daily expenses and calculate total spending.

## Features
- Add daily expenses
- View expense details
- Calculate total expenses
- Manage personal spending

## Technologies Used
- Python
- Basic Python Concepts
- Conditional Statements
- Loops
- User Input

## How to Run
1. Download or clone this repository.
2. Open the project in VS Code.
3. Run the Python file.
4. Enter your expenses and follow the instructions.
